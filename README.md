# BlockSyncDiamond

BlockSyncDiamond is a decentralized, event-driven data-sync framework for scalable, real-time blockchain-platform applications.

BlockSyncDiamond is built to be simple and practical, focusing on doing one thing well.

**Why BlockSyncDiamond?**

## Installation

1. Clone the repository: `git clone https://github.com/harutosati/BlockSyncDiamond.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

BlockSyncDiamond is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
